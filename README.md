# MRMR — prototyp interfejsu v0.3

Otwórz `index.html` w przeglądarce. Wszystkie podstrony są osobnymi plikami HTML i korzystają ze wspólnych `styles.css` oraz `app.js`.

## Co działa
- Nawigacja rozwijana, desktop i mobile.
- 24 podstrony, filtrowanie aktualności i projektów, wyszukiwarka demonstracyjna, lista szkół, karty radnych, komisji i dokumentów.
- Panel CMS demo: dodawanie, edycja i usuwanie przykładowych wpisów, lokalny zapis w `localStorage`, reset danych.
- Walidacja demonstracyjnego formularza i ankiety bez wysyłania danych.

## Czego nie ma
- Backend, logowanie, MFA, role, baza danych, prawdziwa mapa, wysyłka wiadomości, newsletter, oficjalne głosowania, prawdziwe dokumenty i dane radnych.
- Nie jest to gotowy do produkcji serwis publiczny ani deklaracja zgodności z WCAG/RODO/KRI.
- Nie wpisuj danych osobowych w lokalny CMS.

## Kolejny etap
Po ustaleniach z IT urzędu: technologia hostingu, API, CMS, uprawnienia, SSO/MFA, publikacja dokumentów, polityki prywatności, audyty i testy.
